# gruvbox-dark.yazi

Yazi flavor for the **gruvbox** rice. Generated by remapping the current-schema
`catppuccin-mocha` flavor to the gruvbox dark palette — os-rice keeps flavors on
the installed yazi version's schema so they don't drift out of format (see the
yazi 26.x `name`→`url` / `[manager]`→`[mgr]` breakage that this avoids).

Palette: bg `#282828`, fg `#ebdbb2`, red `#fb4934`, green `#b8bb26`,
yellow `#fabd2f`, blue `#83a598`, aqua `#8ec07c`, orange `#fe8019`,
purple `#d3869b`.

Selected by `os-rice/rices/gruvbox/config/yazi/theme.toml`. Code-preview syntax
highlighting falls back to yazi's built-in theme (no bundled tmTheme).
