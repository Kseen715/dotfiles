# xin.yazi

Yazi flavor for the **xin** rice — minimal, terminal-native. Generated by
remapping the current-schema `catppuccin-mocha` flavor onto ANSI color names
(not hex), so the file manager inherits whatever palette the terminal is running.
This matches xin's starship palette, which also uses named colors.

Mapping: accents → `cyan`/`blue`/`green`/`yellow`/`red`/`magenta`,
backgrounds → `reset`/`black`/`darkgray`, foregrounds → `white`/`gray`.

Selected by `os-rice/rices/xin/config/yazi/theme.toml`. Code-preview syntax
highlighting falls back to yazi's built-in theme (no bundled tmTheme).
