# nord.yazi

Yazi flavor for the **nord** rice. Generated by remapping the current-schema
`catppuccin-mocha` flavor to the Nord palette — os-rice keeps flavors on the
installed yazi version's schema so they don't drift out of format.

Palette: Polar Night `#2e3440`/`#3b4252`/`#434c5e`/`#4c566a`, Snow Storm
`#d8dee9`/`#e5e9f0`/`#eceff4`, Frost `#8fbcbb`/`#88c0d0`/`#81a1c1`/`#5e81ac`,
Aurora `#bf616a`/`#d08770`/`#ebcb8b`/`#a3be8c`/`#b48ead`.

Selected by `os-rice/rices/nord/config/yazi/theme.toml`. Code-preview syntax
highlighting falls back to yazi's built-in theme (no bundled tmTheme).
