# WezTerm

Config for [WezTerm](https://github.com/wezterm/wezterm). Themed through
`wezterm-theme.toml.tmpl`, rendered per theme —
[[os-rice/DESIGN#6b. A theme is a palette, not a directory of app configs|DESIGN 6b]].

Installed by `modules/wezterm.c` (Windows) and `modules/wezterm.sh` (POSIX).
